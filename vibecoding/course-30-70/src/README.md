# Вайбкодинг: курс 30/70

Курс, в котором 30% времени уходит на теорию и 70% — на практику с ИИ-агентом.
Цель: к концу курса вы умеете доводить рабочий продукт от идеи до деплоя,
не написав вручную ни одной функции.

## Что внутри

| Файл | Зачем |
|---|---|
| `01-programma.md` | Программа: 8 модулей + капстоун, тайминг каждой части |
| `02-teoriya.md` | Вся теория курса, сжато, по модулям |
| `03-praktika.md` | Задания к каждому модулю с критериями приёмки |
| `04-promptoteka.md` | 32 готовых промпта под конкретные ситуации |
| `05-proekty.md` | 10 проектов для капстоуна, с оценкой сложности |
| `06-tracker.md` | Чек-лист прогресса, заполняется руками |

## Тайминг: как получается ровно 30/70

Всего **1380 минут (23 часа)**.

- Теория: **414 минут — 30.0%**
- Практика: **966 минут — 70.0%**

Внутри модуля: 150 минут = 45 теории + 105 практики.
Капстоун: 180 минут = 54 теории (разбор) + 126 практики (сборка).

Правило, которое важнее тайминга: **теория не читается заранее**. Открываете
модуль, читаете его теорию (45 минут, не больше), сразу делаете практику того же
модуля. Не прочитали практику — не переходите дальше.

## Как проходить

1. Один модуль = один вечер (2.5 часа) или два вечера по 75 минут.
2. Всё, что делаете в практике, кладёте в git. Первый коммит — до первой строки
   кода от ИИ.
3. Каждое задание заканчивается отметкой в `06-tracker.md`. Нет отметки — модуль
   не пройден.
4. Капстоун начинаете не раньше 6-го модуля.

## Что нужно поставить заранее

- **Агент с доступом к файлам**: Claude Code, Cursor, Codex CLI, Windsurf —
  любой, который сам читает и правит файлы. Чат в браузере для этого курса
  не подходит: он не видит ваш проект.
- **git** и аккаунт на GitHub.
- **Node.js LTS** и **Python 3.12** — на них построены все проекты.
- Один аккаунт на Vercel или Netlify (бесплатный) для деплоя.

## Три правила курса

1. **Не принимайте код, который не можете проверить.** Проверка — это не «выглядит
   нормально», это запуск, тест или явно наблюдаемое поведение.
2. **Маленький шаг = один коммит.** Если агент сломал — `git reset --hard` и шаг
   заново, а не «давай починим ещё 40 файлов».
3. **Спека до кода.** Пока задача не сформулирована в 5–10 строк с критериями
   готовности, агент будет угадывать, а вы — переделывать.

## Что вы получите на выходе

- 8 отработанных навыков: от постановки задачи до деплоя.
- Один задеплоенный проект с публичной ссылкой.
- Свою промптотеку, дополненную под ваши задачи.
- Привычку коммитить и проверять — то, что отличает вайбкодинг от рулетки.

## Как пересобрать HTML

Страницы этого курса собраны из Markdown-исходников, которые лежат в `src/`.
Правьте `.md`, затем из папки `src/`:

```bash
pip install markdown
python build_html.py
```

Скрипт перезапишет HTML-страницы рядом (в корне `course-30-70/`) —
`index.html`, `01-programma.html` … `06-tracker.html`.
Проверка результата: `python check_html.py`.

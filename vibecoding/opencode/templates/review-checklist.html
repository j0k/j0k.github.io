Чек-лист ревью диффа

Порядок важен: начинайте с удалений.

1. Удаления (−)

  • Ни одна проверка (auth, валидация, права) не удалена.
  • Не удалены обработчики ошибок.
  • Не удалены тесты без замены.
  • Не удалён код, который ещё используется (grep по имени пуст).

2. Логика (+)

  • Условия (if/else, границы) не изменены незаметно.
  • Нет except Exception: pass, catch {}.
  • Нет заглушек: return None # TODO, return True.
  • Нет магических чисел без пояснения.
  • Нет отладочных print / console.log.

3. Тесты

  • Тесты проверяют поведение, а не is not None.
  • Есть граничные кейсы (пусто, None, максимум).
  • Нет skip / xfail / only.
  • Тест падает, если сломать код (проверено мутацией).

4. Безопасность

  • Нет секретов (grep -rn "sk-", токены, пароли).
  • SQL/команды параметризованы.
  • Вход валидируется на границе.
  • Новая зависимость: имя проверено на typosquatting.

5. Границы задачи

  • Изменения только в оговорённых файлах.
  • Нет «попутных улучшений».
  • Размер диффа соответствует плану.

6. Итог

  • Дифф прочитан целиком.
  • ./scripts/check.sh зелёный.
  • Замечания сформулированы как файл:строка — проблема — фикс.

Модуль 06 — Практика: посчитать и выбрать

Время: 120 минут · Артефакт: labs/06-economics/

Задание 1. Ручной расчёт (20 мин)

Дано:

модель A: input $0.25 / 1M, output $1.25 / 1M
модель B: input $5.00 / 1M, output $30.00 / 1M

Задача: агентный цикл из 8 шагов, на каждом шаге контекст ~40k токенов input и ~500 токенов output.

Посчитайте:

  1. Стоимость модели A.
  2. Стоимость модели B.
  3. Во сколько раз дороже B.
  4. При каком числе шагов B станет дешевле, если B решает задачу за 3 шага, а A за 12?

Приёмка: расчёт с формулами в отчёте.

Задание 2. Измерить реальную сессию (30 мин)

Выполните одну и ту же задачу двумя способами:

A) одна большая сессия с 3 задачами
B) три отдельные сессии

Сравните:

opencode stats

или счётчик стоимости в интерфейсе.

Записать: токены input/output, стоимость, время. Сделайте вывод: что дешевле и почему.

Задание 3. Кэш в действии (25 мин)

Проведите 5 однотипных правок подряд в одной сессии (например, переименование в 5 файлах), не меняя инструкции.

Затем то же самое, но с изменением AGENTS.md между шагами.

Записать: разницу в стоимости (кэш-хиты видны в статистике провайдера/OpenCode). Вывод: как структурировать запросы, чтобы кэш работал.

Задание 4. Таблица выбора моделей (30 мин)

Составьте таблицу для своего проекта:

Задача Модель Почему Ожид. стоимость
переименование fast шаблон $
новые тесты fast/balanced по образцу $
новая фича balanced нужен контекст $
архитектурный рефакторинг frontier нужно думать $
анализ инцидента по логам long-context 500k токенов $

Приёмка: минимум 5 строк с обоснованием, не «самая умная».

Задание 5. Сравнить две модели на одной задаче (15 мин)

Возьмите задачу средней сложности. Выполните на дешёвой и на дорогой модели. Сравните:

дешёвая дорогая
итераций до зелёных тестов
стоимость
ваш тайм на ревью
качество диффа (1–5)

Вывод: какая модель выгоднее для этого класса задач.

Критерии сдачи

  • Ручной расчёт с формулами и ответом на вопрос про 3 vs 12 шагов.
  • Реальные измерения двух стратегий сессий.
  • Разбор эффекта кэша.
  • Таблица выбора моделей на 5+ строк.
  • Сравнение двух моделей с выводом.

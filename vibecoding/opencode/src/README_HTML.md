# Вайбкодинг с OpenCode — HTML-версия курса

Это статическая копия курса «Вайбкодинг с OpenCode» (исходники лежали в `C:\git\Vibecode\opencode`).
Открывается локально без интернета; вся навигация внутри папки.

- **`index.html`** — программа, расписание, правила и оценки.
- **`modules/`** — 11 модулей, у каждого отдельная страница теории и практики.
- **`templates/`** — шаблоны артефактов (спека, `AGENTS.md`, чек-лист ревью, ретро).
- **`rubric` · `glossary` · `resources` · `progress` · `labs`** — дополнительные материалы курса.
- **`build.html`** — как пересобрать сайт из Markdown.
- **`src/`** — Markdown-исходники и сборщик `build.py`.

Правила курса коротко: не принимать непрочитанный дифф, не брать задачу без оракула,
одна задача — одна сессия. Подробнее — на `index.html`.

## Exigences pour les rapports

Tout `report.md` contient :

```markdown
# Rapport : module NN

## Tâche N
**Attendu :**
**Réel :**
**Conclusion :**

## Métriques
- Temps :
- Coût :
- Itérations :

## Ce que j'emporterai dans ma pratique
1.
```

Un rapport sans la section « Attendu / Réel / Conclusion » n'est pas accepté : la conclusion compte, pas le fait d'avoir terminé.

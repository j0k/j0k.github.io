# Critères d'évaluation du cours

Score de passage — **70 %**. Le projet final est obligatoire.

---

## 1. Compréhension (25 %)

Évaluée par les réponses aux « checklists de compréhension » de chaque module.

| Note | Description |
| --- | --- |
| 5 | Explique avec ses propres mots, donne un exemple tiré de sa pratique |
| 4 | Explique correctement, sans exemple de sa pratique |
| 3 | Récite la définition, se perd à l'application |
| 2 | Partiellement correct, concepts clés confondus |
| 1 | Ne répond pas / répond faux |

Résultat : moyenne sur les modules ≥ 3,5.

---

## 2. Pratique (45 %)

Chaque module est rendu selon les critères d'acceptation de `practice.md`.

| Note | Description |
| --- | --- |
| 5 | Tous les points de la checklist sont faits, il y a des conclusions personnelles |
| 4 | Tous les points faits, conclusions formelles |
| 3 | 1–2 points non faits |
| 2 | La moitié des points non faits |
| 1 | Artefact absent ou copié |

Est également évaluée la **qualité de l'artefact**, pas seulement sa présence :

- `AGENTS.md` — uniquement des règles vérifiables, ≤ 40 lignes ;
- spec — des exigences vérifiables, un bloc « hors périmètre » ;
- rapports — contiennent attendu/réel/conclusion, pas « c'est fait ».

---

## 3. Projet final (30 %)

| Étape | Poids | Critère pour « 5 » |
| --- | --- | --- |
| Spec | 15 % | exigences vérifiables, périmètre clair |
| Plan | 10 % | 4–8 étapes, chacune ≤ 2 fichiers |
| Implémentation | 30 % | un commit par étape, dépôt vert, aucun revert |
| Revue | 20 % | ≥ 3 vrais problèmes trouvés |
| Merge | 10 % | diff propre, CI verte |
| Rétrospective | 15 % | métriques honnêtes, une règle concrète |

**Condition obligatoire :** à la soutenance, montrez l'endroit où vous avez refusé la suggestion de l'agent.

---

## Barème final

| Points | Note |
| --- | --- |
| 90–100 | excellent |
| 75–89 | bien |
| 70–74 | satisfaisant |
| < 70 | non validé |

---

## Ce qui compte comme plagiat

- Un artefact copié sur un camarade sans travail personnel.
- Un `AGENTS.md` qui ne correspond pas au projet (les commandes ne fonctionnent pas).
- Un rapport sans conclusions : « j'ai fait le devoir » au lieu de « ce que j'ai appris ».

Pas un plagiat : utiliser un agent pour faire les devoirs — c'est l'objet même du cours.

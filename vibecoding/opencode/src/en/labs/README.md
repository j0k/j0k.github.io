## Report requirements

Any `report.md` contains:

```markdown
# Report: module NN

## Task N
**Expected:**
**Actual:**
**Conclusion:**

## Metrics
- Time:
- Cost:
- Iterations:

## What I will take into practice
1.
```

A report without the "Expected / Actual / Conclusion" section is not accepted: the conclusion matters, not the fact of completion.

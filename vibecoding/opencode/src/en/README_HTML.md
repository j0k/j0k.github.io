# Vibe coding with OpenCode — HTML version of the course

This is a static copy of the course "Vibe coding with OpenCode" (the sources were in `C:\git\Vibecode\opencode`).
It opens locally without the internet; all navigation is inside the folder.

- **`index.html`** — syllabus, schedule, rules, and grading.
- **`modules/`** — 11 modules, each with a separate theory and practice page.
- **`templates/`** — artifact templates (spec, `AGENTS.md`, review checklist, retro).
- **`rubric` · `glossary` · `resources` · `progress` · `labs`** — additional course materials.
- **`build.html`** — how to rebuild the site from Markdown.
- **`src/`** — Markdown sources and the `build.py` builder.

Course rules in short: do not accept an unread diff, do not take a task without an oracle,
one task — one session. More on `index.html`.

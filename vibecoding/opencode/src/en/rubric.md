# Course grading criteria

Passing score — **70%**. The capstone is mandatory.

---

## 1. Understanding (25%)

Graded by the answers to the "comprehension checklists" of each module.

| Score | Description |
| --- | --- |
| 5 | Explains in their own words, gives an example from their own practice |
| 4 | Explains correctly, no example from practice |
| 3 | Recites the definition, gets confused when applying it |
| 2 | Partly correct, key concepts mixed up |
| 1 | Does not answer / answers incorrectly |

Result: average across modules ≥ 3.5.

---

## 2. Practice (45%)

Each module is submitted against the acceptance criteria from `practice.md`.

| Score | Description |
| --- | --- |
| 5 | All checklist items done, there are original conclusions |
| 4 | All items done, conclusions are formal |
| 3 | 1–2 items not done |
| 2 | Half of the items not done |
| 1 | Artifact missing or copied |

Additionally graded is the **quality of the artifact**, not just its presence:

- `AGENTS.md` — only verifiable rules, ≤ 40 lines;
- spec — requirements are verifiable, there is an "out of scope" block;
- reports — contain expectation/actual/conclusion, not "done it".

---

## 3. Capstone (30%)

| Stage | Weight | Criterion for "5" |
| --- | --- | --- |
| Spec | 15% | verifiable requirements, clear boundaries |
| Plan | 10% | 4–8 steps, each ≤ 2 files |
| Implementation | 30% | one commit per step, repo green, no reverts |
| Review | 20% | ≥ 3 real problems found |
| Merge | 10% | clean diff, CI green |
| Retro | 15% | honest metrics, a concrete rule |

**Mandatory condition:** at the defence, show the place where you rejected the agent's suggestion.

---

## Final scale

| Points | Grade |
| --- | --- |
| 90–100 | excellent |
| 75–89 | good |
| 70–74 | satisfactory |
| < 70 | not passed |

---

## What counts as plagiarism

- An artifact copied from a classmate without your own work.
- An `AGENTS.md` that does not match the project (the commands do not work).
- A report without conclusions: "completed the assignment" instead of "what I learned".

Not plagiarism: using an agent to do the assignments — that is the subject of the course.

# Критерии оценки курса

Проходной балл — **70%**. Капстоун обязателен.

---

## 1. Понимание (25%)

Оценивается по ответам на «чек-листы понимания» каждого модуля.

| Балл | Описание |
| --- | --- |
| 5 | Объясняет своими словами, приводит пример из своей практики |
| 4 | Объясняет верно, пример из практики отсутствует |
| 3 | Пересказывает определение, путается в применении |
| 2 | Частично верно, ключевые понятия смешаны |
| 1 | Не отвечает / отвечает неверно |

Итог: среднее по модулям ≥ 3.5.

---

## 2. Практика (45%)

Каждый модуль сдаётся по критериям приёмки из `practice.md`.

| Балл | Описание |
| --- | --- |
| 5 | Все пункты чек-листа выполнены, есть собственные выводы |
| 4 | Все пункты выполнены, выводы формальные |
| 3 | 1–2 пункта не выполнены |
| 2 | Половина пунктов не выполнена |
| 1 | Артефакт отсутствует или скопирован |

Дополнительно оценивается **качество артефакта**, а не только наличие:

- `AGENTS.md` — только проверяемые правила, ≤ 40 строк;
- спека — требования проверяемы, есть блок «не входит»;
- отчёты — есть ожидание/факт/вывод, а не «сделал».

---

## 3. Капстоун (30%)

| Этап | Вес | Критерий «5» |
| --- | --- | --- |
| Спека | 15% | проверяемые требования, чёткие границы |
| План | 10% | 4–8 шагов, каждый ≤ 2 файла |
| Реализация | 30% | коммит на шаг, репо зелёный, нет откатов |
| Ревью | 20% | найдены ≥ 3 реальные проблемы |
| Мерж | 10% | чистый дифф, CI зелёный |
| Ретро | 15% | честные метрики, конкретное правило |

**Обязательное условие:** на защите показать место, где вы отклонили предложение агента.

---

## Шкала итога

| Баллы | Оценка |
| --- | --- |
| 90–100 | отлично |
| 75–89 | хорошо |
| 70–74 | удовлетворительно |
| < 70 | не зачтено |

---

## Что считается плагиатом

- Артефакт, скопированный у однокурсника без собственной работы.
- `AGENTS.md`, не соответствующий проекту (команды не работают).
- Отчёт без выводов: «выполнил задание» вместо «что узнал».

Не плагиат: использование агента для выполнения заданий — это и есть предмет курса.

# Теория

## 1. Зачем кастомизировать

Агент по умолчанию — универсальный. Ваш проект — конкретный.
Кастомизация превращает общие знания модели в ваши процессы.

Четыре механизма:

| Механизм | Что это | Когда |
| --- | --- | --- |
| **Skill** | папка с инструкциями + ресурсами, подключается по описанию | повторяемый процесс («как деплоить», «как писать миграции») |
| **Command** | именованный шаблон промпта (`/review`, `/test`) | частые запросы |
| **Subagent** | отдельный агент со своими правами и моделью | разведка, ревью, параллельная работа |
| **MCP** | внешний сервер с инструментами | Jira, БД, браузер, внутренние API |

## 2. Skill

Навык — это файл `SKILL.md` с описанием, когда его применять:

```markdown
---
name: deploy
description: Как безопасно выкатывать релиз на staging и prod
---

# Деплой
1. Проверить, что main зелёный
2. Собрать образ: ...
3. ...
```

Ключ: **description** определяет, когда агент сам подхватит навык.
Плохое описание = навык никогда не используется.

## 3. Command

```jsonc
{
  "commands": {
    "review": {
      "description": "Строгое ревью текущего диффа",
      "template": "Ты строгий ревьюер. Проверь `git diff` на: ... Только проблемы."
    }
  }
}
```

Вызов: `/review`. Экономит ввод и стандартизирует качество.

## 4. Subagent

Отдельная сессия с собственными правами:

```jsonc
{
  "agents": {
    "scout": {
      "description": "Разведка по репозиторию без правок",
      "mode": "subagent",
      "permissions": [
        { "action": "edit", "resource": "*", "effect": "deny" },
        { "action": "shell", "resource": "*", "effect": "deny" }
      ]
    }
  }
}
```

Польза: не засоряет основной контекст, нельзя случайно изменить код.

## 5. MCP

Протокол, по которому агент получает внешние инструменты. Примеры: доступ к БД,
Jira, браузер, внутренние API.

Правила безопасности:

- MCP-сервер — это **код с вашими правами**, доверяйте только проверенным;
- предпочитайте OAuth вместо вставки ключа в конфиг;
- ограничивайте: read-only, если нужен только просмотр.

## 6. Как не утонуть в кастомизации

Начинайте с проблемы, а не с механизма:

```
Повторяю один и тот же промпт 5 раз в неделю → Command
Есть процесс из 10 шагов → Skill
Нужно изолировать разведку → Subagent
Нужны данные из внешней системы → MCP
```

Обратный порядок («сделаю MCP, потому что модно») даёт мусор в конфиге.

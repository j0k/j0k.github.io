**Время:** 80 минут · **Артефакт:** `labs/00-setup.md`

## Задание 1. Проверить окружение (10 мин)

```bash
git --version
opencode --version
```

Затем в терминале:

```bash
mkdir -p ~/edu/sandbox && cd ~/edu/sandbox
git init
printf 'print("hello")\n' > app.py
git add . && git commit -m "init"
```

Запустите `opencode` и спросите:

```
Что за проект в этой папке? Какие файлы и что они делают?
```

**Приёмка:** агент назвал `app.py` и его содержимое, не выдумал лишние файлы.

## Задание 2. Первое «нет» (15 мин)

Попросите агента сделать заведомо вредное действие:

```
Удали все файлы в этой папке и создай новый проект на Rust.
```

**Не подтверждайте** запрос на изменение сразу — прочитайте, что он собирается делать.

Ответьте в `labs/00-setup.md`:

- Показал ли агент список изменений до выполнения?
- Понятно ли из запроса, что именно будет удалено?
- Что произойдёт, если нажать «Always allow» на такое действие?

Урок: **права — это не бюрократия, это тормоз перед необратимым.**

## Задание 3. Границы компетенции (20 мин)

Задайте три вопроса, на которые знаете точный ответ:

```
1. Какая версия Python установлена? (проверьте: python3 --version)
2. Сколько строк в app.py?
3. Какая последняя версия <ваша библиотека>?
```

Сверьте ответы с фактами.

**Приёмка:** в `labs/00-setup.md` — таблица «вопрос / ответ агента / факт / совпало?».

Вывод, который нужно сформулировать самостоятельно: почему третий вопрос опаснее первых двух.

## Задание 4. Ветка как страховка (20 мин)

```bash
git checkout -b agent-experiment
```

Попросите агента добавить в `app.py` функцию `add(a, b)` и тест на неё.
Затем:

```bash
git diff
```

Прочитайте дифф целиком. Если всё ок:

```bash
git add . && git commit -m "add add()"
git checkout main && git branch -D agent-experiment   # или слейте, если хотите оставить
```

**Приёмка:** в отчёте — вывод `git diff` (можно сокращённый) и одна фраза: что бы вы
отклонили в этом диффе, если бы он был в 10 раз больше.

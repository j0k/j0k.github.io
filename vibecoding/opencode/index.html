Вайбкодинг с OpenCode — практический курс

Курс о том, как получать предсказуемый результат от AI-агентов в разработке. Не про «секретные промпты», а про контекст, проверку и инженерную дисциплину.

Автор: команда курса · Версия 1.0 · OpenCode V2

Чему вы научитесь

К концу курса вы сможете:

  1. Объяснить, как устроена LLM и почему она ошибается, — без мистики.
  2. Сформулировать задачу так, чтобы агент выдавал рабочий код с первого-второго раза.
  3. Настроить проект под агента: AGENTS.md, права, команды сборки и тестов.
  4. Работать в цикле «спека → план → маленький дифф → проверка → коммит».
  5. Читать диффы агента и находить опасные изменения.
  6. Считать стоимость сессии и выбирать модель под задачу, а не «самую умную».
  7. Собрать собственный инструментарий: навыки, команды, субагенты.

Для кого

  • Студенты, предприниматели, маркетологи, эксперты, фаундеры.
  • Все, кто пробовал «попросить ChatGPT написать проект» и получил кашу.

Требуется заранее: git (ветки, дифф, откат), терминал, один язык программирования с тестами (Python/JS/Go/Java — любой), установленный OpenCode.

Проверка готовности:

git --version
opencode --version
node --version   # или python3 --version

Как устроен курс

теория   ~40%  — понятия и ментальные модели, без воды
практика ~60%  — упражнения с критериями приёмки

Каждый модуль — папка с двумя обязательными файлами:

Файл Что внутри
README.md теория: понятия, мини-лекция, вопросы на понимание
practice.md упражнения, критерии приёмки, время

Правило курса: модуль не пройден, пока не сдан артефакт в labs/.

Оценка

Часть Вес Что оценивается
Понимание 25% ответы на вопросы модулей, устная защита
Практика 45% артефакты в labs/, прохождение критериев приёмки
Капстоун 30% фича до зелёного CI + ретро по метрикам

Проходной балл — 70%, капстоун обязателен. Подробно: rubric.md.

Три правила, важнее всего остального

  1. Не принимать дифф, который не прочитал. Вайбкодинг без чтения диффа — кредит под 300%.
  2. Нет оракула — нет задачи. Если результат нельзя проверить командой, задача не готова к агенту.
  3. Одна задача — одна сессия. Смешивание целей в одном контексте — главная причина «модель отупела».

С чего начать прямо сейчас

  1. Прочитать modules/00-orientation/README.md.
  2. Заполнить progress.md — поставить дату старта.
  3. Открыть терминал в своём учебном проекте и запустить opencode.

# Вайбкодинг с OpenCode — HTML-версия курса

Сайт собран из Markdown-исходников курса, который лежит в `src/`.
Каждая страница самодостаточна: общий CSS в `assets/style.css`, внешних зависимостей нет.

## Структура

```
opencode/
├── index.html              обзор курса: программа, расписание, оценки
├── modules/
│   ├── NN-slug.html        теория модуля (бывший README.md)
│   └── NN-slug-practice.html   практика модуля (бывший practice.md)
├── templates/
│   ├── spec.html
│   ├── agents.html
│   ├── review-checklist.html
│   └── retro.html
├── templates.html          оглавление шаблонов
├── rubric.html             критерии оценки
├── glossary.html           глоссарий
├── resources.html          что читать дальше
├── progress.html           трекер прогресса
├── labs.html               куда сдавать артефакты
├── assets/style.css        общий стиль
└── src/                    markdown-исходники и сборщик
```

## Как пересобрать

Правьте Markdown в `src/`, затем:

```bash
cd src
python build.py
```

Нужен пакет `markdown`:

```bash
pip install markdown
```

Сборщик сам переписывает ссылки `*.md` во внутренние `.html` и собирает
навигацию по модулям, поэтому руками ссылки в HTML трогать не нужно.

## Что добавлено при сборке

- Единый сайдбар со всеми модулями (теория + практика) и материалами.
- Переходы «теория ↔ практика» в шапке страницы модуля и пейджер внизу.
- Чек-листы (`- [ ]`) стали кликабельными; прогресс сохраняется в `localStorage`
  отдельно для каждой страницы.
- Таблицы с чекбоксами (трекер прогресса) тоже кликабельные.
- Печать: `Ctrl+P` даёт чистую версию без сайдбара и прогресс-бара.
